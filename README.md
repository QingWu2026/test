# Descriptions: Structure of a general virtual coin's codes
1. Generate a node and its net
2. An observer, without voting rights
3. A participant, with voting rights, agreed by node to join the net
4. The observer applies to join the net as a participant
5. If both nodes agree, the observer becomes a participant with voting rights
-- else, observer without voting rights
